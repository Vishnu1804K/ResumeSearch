# ResumeBuilder 

This project is a resume building application consisting of an Angular frontend and a Java Spring Boot backend.

## Project Structure

- **`client-ng/`**: Angular frontend application.
- **`backend-java/`**: Spring Boot backend application.

## Getting Started

### Backend
Navigate to `backend-java/` and run:
```bash
mvn spring-boot:run
```

### Frontend
Navigate to `client-ng/` and run:
```bash
npm install
npm start
```

Refer to `docs-existing-architecture.md` for detailed technical information.
